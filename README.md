## Government Hospital Management System

Jeevanta is a centralized Government Hospital Management System designed to manage hospital operations including:

- Patient Management
- Authentication and Role-Based Access Control
- Appointment Management
- Clinical Records
- Laboratory Management
- Pharmacy Management
- Nursing Operations
- Administration

## Technology Stack

### Frontend

- React.js
- Vite

### Backend

- Node.js
- Express.js

### Database

- PostgreSQL
